# Data Cleaning & Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing an E-commerce sales dataset using Python and Pandas.

## Objectives
- Handle missing values
- Remove duplicate records
- Clean text columns
- Convert date columns into proper datetime format
- Validate data consistency

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

## Dataset Features
- CustomerID
- Product
- Quantity
- UnitPrice
- TotalPrice
- PaymentMethod
- CouponCode
- OrderStatus
- ReferralSource
- Date

## Data Cleaning Steps
1. Loaded dataset from Excel file
2. Checked dataset structure and data types
3. Handled missing CouponCode values
4. Removed duplicate records
5. Cleaned text columns
6. Converted Date column to datetime
7. Validated Quantity and UnitPrice values
8. Verified TotalPrice calculations

## Results
- Clean dataset generated
- Improved data quality
- Ready for analysis and visualization
